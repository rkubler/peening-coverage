# User guide

`local_coverage_guide.pdf` is the user and theory guide of this simulator: the idea, the screen, the model and its equations, every parameter and result displayed, coverage above 100 % (NF L 06-832), things to try and the assumptions.

Online: https://rkubler.github.io/peening-coverage/docs/local_coverage_guide.pdf

## LaTeX sources

`local_coverage_guide.tex` uses the shared preamble `common.tex` and the shared section `nfcov.tex`; the screenshots are in `img/`. To compile, run `pdflatex local_coverage_guide.tex` three times in this folder.
